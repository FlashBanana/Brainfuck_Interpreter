## ⚠️ WARNING
The program needs obligatorily either the parameter --file or --text to work while the other 2 are optional 

## ⭐ To test run the program from command line with these parameters:

**-f | --file** requires a file for input

**-t | --text** requires text for input

**-d | --debug** to print debug in console

**-sd | --save--debug** to save the memory dump in a file named **_"finalDump.txt"_**
